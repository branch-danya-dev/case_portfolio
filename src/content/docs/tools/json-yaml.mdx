Для работы с контрактами и сообщениями интеграций: отформатировать ответ API, перевести фрагмент OpenAPI из YAML в JSON, найти, где сломался документ, проверить пример сообщения по схеме. Пример на вкладке проверки — схема кадрового события из [AsyncAPI-контракта кейса](/case/04-integrations/api-hr-events/) и событие с ошибками: неизвестный `eventType`, `personId` без префикса `P-`, лишнее поле.

<JsonYaml client:load />

Проверка — по JSON Schema draft-07 (библиотека Ajv, форматы `date-time`, `uuid`, `email` и др. — пакет ajv-formats); схемы в OpenAPI 3.0 и AsyncAPI близки к ней, но не идентичны — например, `nullable` из OpenAPI 3.0 здесь игнорируется. Всё считается в браузере: в отличие от онлайн-форматтеров, данные никуда не отправляются. Но тексты сохраняются в хранилище этого браузера, чтобы не пропасть при перезагрузке, — после работы с персональными данными очистите поля.
