Полноценный редактор BPMN 2.0 (bpmn-js, тот же движок, что в Camunda Modeler). Элементы — из палитры слева; у выделенного элемента появляется контекстное меню: добавить следующий шаг, сменить тип, соединить, удалить. Двойной щелчок — редактировать подпись.

Файл сохраняется в стандартном формате BPMN 2.0 XML — его откроют Camunda Modeler, demo.bpmn.io и другие инструменты. Схемы кейса можно открыть из списка «Пример…» и переделать, например, для упражнений из [шпаргалки кейса](/case/cheatsheet/#10-вопросы-для-самопроверки-и-упражнения).
