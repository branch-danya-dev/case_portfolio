import ArtifactGenerator from '../../../components/tools/ArtifactGenerator.tsx';

Заполните поля — справа появится готовый Markdown для Confluence, GitLab или документа. Блок **«Проверка»** подсказывает типичные ошибки: нет ценности в истории, альтернатива не привязана к шагу, в НФТ нет числа, размытые слова вроде «быстро» и «удобно», у ADR одна альтернатива. Кнопка **«Заполнить примером из кейса»** показывает, как шаблон выглядит на настоящем артефакте IDM-JOINER.

<ArtifactGenerator client:load />

Черновик каждого шаблона сохраняется в этом браузере и никуда не отправляется. В полях-списках каждая строка — отдельный элемент, ячейки таблицы разделяются символом `|`.
