Три способа из раздела [«Приоритизация»](/requirements/prioritization/): **MoSCoW** — категории, понятные бизнесу; **RICE** — скоринг улучшений по охвату, влиянию, уверенности и затратам; **WSJF** — очередь по стоимости задержки на единицу размера. Результат любой вкладки копируется таблицей Markdown для Confluence или задачи.

Числа в RICE и WSJF — опора для разговора, а не решение: обсудите с владельцем продукта, почему оценки такие. Данные хранятся только в этом браузере.
