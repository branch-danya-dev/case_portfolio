## Источники и техники

**Источники:** люди (заказчик, пользователи, ИБ, аудит, смежные системы, эксплуатация) · документы (регламенты, нормативка, договоры) · системы (интерфейс, БД, логи, API) · данные и статистика. Важное — подтверждать **двумя источниками**.

| Техника | Когда |
|---|---|
| Интервью | Глубина, мнение одного человека |
| Воркшоп | Договориться группе, быстро согласовать |
| Наблюдение | Процесс «на автомате» |
| Анкета | Статистика по многим людям |
| Анализ документов | Правила, термины, нормативка |
| Анализ систем и данных | Что реально автоматизировано, объёмы |
| Прототип | Интерфейс: «увижу — пойму» |

Порядок: **документы и системы → интервью → воркшоп для согласования**.

</section>

<section>

## Интервью

Цель → подготовка (документы, вопросы, повестка) → **открытые** вопросы → **уточняющие** («почему?», «сколько?») → **исключения** («а если…?») → **закрытые** для подтверждения → протокол **в течение суток**.

**Приёмы:** «покажите», «расскажите о последнем случае», пауза после ответа, цифры вместо «долго», не предлагать решение раньше времени. **«5 почему»** — от симптома к корневой причине.

**Протокол:** что узнали (с источником) · решения (кто принял) · открытые вопросы (кто, срок) · следующие шаги.

</section>

<section>

## Воркшоп

Цель и **артефакт на выходе** · 5–8 участников с правом решения · черновик заранее · правила и «парковка» · фасилитатор нейтрален · решения фиксируются сразу · итоги с ответственными · протокол за сутки.

**Форматы:** моделирование процесса · story mapping · event storming · приоритизация · мозговой штурм · разбор маппинга.

</section>

<section>

## Анализ документов и систем

**Документы:** роли, шаги, сроки, правила, термины — со ссылкой на редакцию и пункт. Регламент ≠ реальность: **расхождения — находка**.

**Системы:** интерфейс (поля, проверки, статусы) · БД (сущности, ключи, справочники) · профилирование (объём, заполненность, дубликаты, «сироты») · логи · интеграции · обращения в поддержку · «тихие» функции.

</section>

<section>

## Стейкхолдеры

Найти (процесс, контекст, «кого ещё?», обязательные: ИБ, аудит, юристы, эксплуатация) → интерес и опасения → влияние × интерес → стратегия → RACI → обновлять.

| | Низкий интерес | Высокий интерес |
|---|---|---|
| **Высокое влияние** | Держать удовлетворёнными | Управлять плотно |
| **Низкое влияние** | Наблюдать | Держать в курсе |

</section>

<section>

## Конфликты

Зафиксировать → проверить термины и факты → **интересы, а не позиции** → варианты с последствиями → эскалация владельцу (A) → журнал решений.

**Кейс:** HRD «руководитель выбирает права» vs CISO «только роли» → роли по умолчанию (BR-03) + заявки с согласованием (BR-05). Ограничение побеждает желание (ADR-003). Отложенное — статус W, а не удаление (BR-12).

**Ошибки:** решать за владельца · «пополам» · замалчивать · эскалировать без вариантов · не записать решение.

</section>
