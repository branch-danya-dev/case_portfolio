## Use case

Актор (внешний; система и таймер тоже) · прецедент «глагол + объект» · граница. **include** — всегда, стрелка от базового; **extend** — при условии, стрелка от расширения к базовому. Оглавление, а не спецификация.

</section>

<section>

## Activity

Начало ● · действие · ромб (решение / слияние, `[условие]`) · fork / join ▬ · дорожки · конец ◉ / конец потока ⊗. Для **алгоритма внутри системы**; бизнес-процесс — BPMN.

</section>

<section>

## Sequence

Линии жизни · синхронный вызов (ждёт) · асинхронный (не ждёт) · ответ — пунктир · активация · `alt` / `opt` / `loop` / `par` / `ref` · `autonumber`.

Mermaid: `->>` синхронный, `-)` асинхронный. PlantUML: `->` вызов, `->>` асинхронный.

Один сценарий — одна диаграмма · ответы на синхронные вызовы · ошибки через `alt` · 6–8 участников. Тайм-аут → повтор с тем же ключом идемпотентности.

</section>

<section>

## State

Состояние — существительное · переход **`событие [условие] / действие`** · начальное ● · конечное ◉ · entry / exit / do. Один объект — одна диаграмма + **таблица переходов** + **запрещённые переходы** (негативные тесты). Ошибки и отмена из каждого состояния.

</section>

<section>

## Class

Ассоциация — линия · агрегация ◇ (часть живёт без целого) · композиция ◆ (не живёт) · обобщение △ · реализация - - △ · зависимость - - >. Кратности `1`, `0..1`, `*`, `1..*`. Видимость `+ - # ~`. Аналитику — доменная модель; хранение — ER.

</section>

<section>

## Component и Deployment

Компонент · предоставляемый интерфейс («леденец») · требуемый («гнездо») · порт. Узел (параллелепипед) · среда выполнения · артефакт · канал с протоколом · сетевые зоны · резервирование под НФТ.

</section>

<section>

## C4

1 **Context** (все) → 2 **Container** (приложения, БД, очереди) → 3 **Component** → 4 Code. Элемент: имя, тип, технология, описание. Стрелка: что и как. Контейнер ≠ Docker. Один уровень — одна диаграмма. Не забыть SIEM, мониторинг, SMS, ServiceDesk.

</section>

<section>

## DFD

Внешняя сущность · процесс (круг / скруглённый) · хранилище (= / открытый прямоугольник) · поток (существительное). Уровни 0 → 1 → 2, баланс входов-выходов. Нельзя: хранилище ↔ хранилище, сущность ↔ сущность напрямую. Для угроз — **границы доверия**.

</section>
