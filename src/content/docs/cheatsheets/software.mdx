## Данные и брокеры

| Задача | Инструмент |
|---|---|
| Клиент любой СУБД, ER схемы | DBeaver (DataGrip, pgAdmin, SQL Developer) |

## Инфраструктура: что смотреть

| Задача | Инструмент |
|---|---|
| Путь операции по `traceId` | Kibana / OpenSearch, Loki; трасса — Jaeger |
| Релиз до и после | Grafana (метрики Prometheus) |
| Версия на среде, упавшие проверки | GitLab CI, Jenkins |
| Заглушка, локальное окружение | Docker |
| Несколько экземпляров, перезапуски | Kubernetes / OpenShift |
| Клиенты, scopes, сроки токенов | Keycloak |
| Секреты интеграций | Vault |
| 429, 502, 504 на входе | API-шлюз |

<section>

## Стек: обязательный минимум

SQL и клиент БД · HTTP и REST (Postman, curl) · чтение OpenAPI · JSON, XML, JSON Schema · Jira и Confluence · BPMN и UML в инструменте диаграмм · брокеры: топик, очередь, DLQ · логи по `traceId` · Git: история и merge request · DevTools.
Уровни — глубина, а не список: **junior** знает и пользуется, **middle** учитывает в требованиях и разбирает сам, **senior** выбирает и обсуждает компромиссы.

</section>

<section>

## Безопасность

Рабочие данные — не в онлайн-сервисы · секреты — не в коллекциях · БД — только чтение и тестовые данные · ПО — из одобренного каталога компании.
