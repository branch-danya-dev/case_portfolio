Практикум дополняет теорию разделов [Процессы](/processes/bpmn/) и [UML и архитектурные диаграммы](/diagrams/choose/): там — **что** означает нотация, здесь — **как** быстро нарисовать диаграмму и проверить её.

Каждая страница практикума устроена одинаково:

1. **Алгоритм построения** — с чего начать, в каком порядке добавлять элементы, когда остановиться.
2. **Синтаксис** во вкладках Mermaid и PlantUML — минимальный рабочий пример и шпаргалка по элементам. Если Mermaid тип не поддерживает — так и сказано.
3. **Визуальный редактор** — draw.io, для BPMN — Camunda Modeler.
4. **Чек-лист** проверки готовой диаграммы — отметки сохраняются в браузере.
5. **«До и после»** — типичная плохая диаграмма, исправленная и разбор изменений.
6. **Упражнение** на кейсе IDM-JOINER — решение спрятано.

У каждого примера Mermaid есть кнопка **«Открыть в песочнице»** — код откроется в [песочнице](/tools/mermaid-sandbox/), где его можно менять.

## Чем рисовать

| Диаграмма | Mermaid | PlantUML | Визуальный редактор |
|---|---|---|---|
| BPMN | Нет | Нет (только приближение) | Camunda Modeler, demo.bpmn.io, [BPMN-редактор сайта](/tools/bpmn-editor/), draw.io |
| Use case | Нет | Да | draw.io, Enterprise Architect |
| Activity | Приближение через flowchart | Да | draw.io |
| Sequence | Да | Да | draw.io |
| State | Да | Да | draw.io |
| Class | Да | Да | draw.io |
| ER | Да (`erDiagram`) | Да (`entity`, нотация «вороньи лапки») | draw.io, DBeaver (из БД) |
| Component | Нет | Да | draw.io |
| Deployment | Нет (есть C4 Deployment) | Да | draw.io |
| C4 | Да, экспериментально | Да (C4-PlantUML в стандартной библиотеке) | draw.io |
| DFD | Приближение через flowchart | Приближение | draw.io (фигуры DFD) |

**Текстовые нотации или визуальный редактор?** Текст (Mermaid, PlantUML) хорош для docs-as-code: хранится в git, видны изменения, диаграмма не «разъезжается». Визуальный редактор — для BPMN, сложных схем с ручной раскладкой и для людей, которым не нужен код.

**Общее про draw.io** (diagrams.net): бесплатный, работает в браузере и как настольное приложение (в том числе без сети), хранит диаграмму в XML-формате `.drawio`; при экспорте в PNG или SVG можно сохранить внутри файла копию диаграммы для последующего редактирования. Фигуры для разных нотаций — в библиотеках фигур, которые подключаются в левой панели.
