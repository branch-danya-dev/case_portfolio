## Чем открывать

| Формат | Инструменты |
|---|---|
| `.md` | VS Code, Obsidian, Typora, GitHub / GitLab, импорт в Confluence |
| `.bpmn` | Camunda Modeler (бесплатный, десктоп), demo.bpmn.io, BPMN-редактор этого сайта |
| `.svg` | Любой браузер |
| `.puml` | VS Code + расширение PlantUML, IntelliJ IDEA, plantuml.com, макрос PlantUML в Confluence |
| `*.openapi.yaml` | Postman, Swagger Editor, IntelliJ IDEA, просмотрщик на странице API этого сайта |
| `*.asyncapi.yaml` | AsyncAPI Studio, просмотрщик на странице API этого сайта |
