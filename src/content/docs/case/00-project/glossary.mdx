Версия 1.0 · Владелец: Системный аналитик

Глоссарий фиксирует, что именно означает термин **в этом проекте**. Если HR, ИБ и разработка понимают слово «роль» по-разному, требования будут противоречить друг другу.

| Термин                       | Определение в проекте                                                                                                         | Не путать с                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Сотрудник                    | Физическое лицо, с которым у банка есть трудовой договор, по данным HRMS                                                      | Учётной записью                      |
| Идентичность (identity)      | Запись о физическом лице в IdM, объединяющая все его учётные записи. Одна на физическое лицо, ключ — `personId` из HRMS       | Учётной записью в конкретной системе |
| Трудоустройство (employment) | Конкретный трудовой договор сотрудника. У совместителя их несколько одновременно, у повторно принятого — несколько во времени | Сотрудником                          |
| Учётная запись (account)     | Запись пользователя в конкретной целевой системе (логин в AD, пользователь АБС)                                               | Идентичностью                        |
| Целевая система (ресурс)     | Система, в которой IdM создаёт учётные записи и выдаёт права: AD, Exchange, АБС, СЭД                                          | Источником данных (HRMS)             |
| Полномочие (entitlement)     | Минимальная единица права в целевой системе: группа AD, роль АБС, роль СЭД                                                    | Бизнес-ролью                         |
| Бизнес-роль                  | Набор полномочий в разных системах, который нужен для работы на должности                                                     | Ролью в АБС (это полномочие)         |
| Базовая роль (birthright)    | Бизнес-роль, которую получает каждый сотрудник банка без запроса                                                              | —                                    |
| Правило назначения роли      | Соответствие «тип подразделения + код должности → бизнес-роль»                                                                | —                                    |
| Кадровое событие             | Сообщение из HRMS о приёме, изменении или отмене приёма                                                                       | Заявкой                              |
| Заявка                       | Запрос на выдачу дополнительных полномочий, проходящий согласование                                                           | Кадровым событием                    |
| Владелец ресурса             | Сотрудник, отвечающий за доступ к целевой системе и согласующий выдачу прав в ней                                             | Администратором ресурса              |
| Администратор ресурса        | Сотрудник, технически исполняющий выдачу прав вручную                                                                         | Владельцем ресурса                   |
| SoD-конфликт                 | Сочетание полномочий, которое нельзя выдавать одному сотруднику (например, ввод и подтверждение операции)                     | —                                    |
| Провижининг                  | Создание учётной записи и выдача полномочий в целевой системе                                                                 | Согласованием                        |
| Коннектор                    | Компонент IdM, который выполняет провижининг в конкретной целевой системе                                                     | Адаптером                            |
| Адаптер АБС                  | Отдельный сервис, предоставляющий REST API для администрирования пользователей АБС                                            | Коннектором IdM                      |
| Задача ручного исполнения    | Задача в ServiceDesk для администратора, создаваемая IdM для систем без коннектора или при сбое                               | Заявкой                              |
| Дата выхода                  | Первый рабочий день сотрудника по приказу (`hireDate`)                                                                        | Датой приказа                        |
| Активация                    | Разблокировка заранее созданных учётных записей в день выхода                                                                 | Созданием учётной записи             |
| Сверка (reconciliation)      | Сравнение данных IdM с источником или целевой системой для поиска расхождений                                                 | Аудитом                              |
