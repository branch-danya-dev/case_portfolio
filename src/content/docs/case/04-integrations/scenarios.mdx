Sequence-диаграмма показывает **порядок сообщений между участниками во времени** для одного сценария. Она отвечает на вопросы разработчика: кто кого вызывает, в каком порядке, что возвращается, что происходит при ошибке. Хорошее правило: на каждый основной сценарий — одна диаграмма успешного пути и отдельные диаграммы для важных ошибок.

## Обозначения PlantUML

| Элемент      | Значение                                                         |
| ------------ | ---------------------------------------------------------------- |
| `->`         | Синхронный вызов                                                 |
| `-->`        | Ответ                                                            |
| `->>`        | Асинхронное сообщение                                            |
| `->x`        | Потерянное сообщение (не дошло до получателя)                    |
| `-[#red]->`  | Цвет стрелки; здесь — для ошибок и таймаутов                     |
| `alt / else` | Альтернативные ветки (условие)                                   |
| `loop`       | Повторение                                                       |
| `== … ==`    | Разделитель этапов во времени                                    |
| `autonumber` | Нумерация шагов — на них удобно ссылаться в требованиях и тестах |
