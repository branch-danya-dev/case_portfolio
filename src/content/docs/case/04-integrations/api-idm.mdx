Публичный API ядра IdM: доступы сотрудника с основаниями, каталог полномочий, заявки на доступ и решения по ним, закрытие ручных задач (webhook от ServiceDesk, [INT-06](/case/04-integrations/integration-map/#int-06)). Ошибки — в формате RFC 7807 (`application/problem+json`).

На что посмотреть при разборе: как описаны ошибки и коды ответов, какие параметры у списков, где нужен ключ идемпотентности, как схемы переиспользуются через `components/schemas`.
