Учебный, но реалистичный комплект проектной документации системного анализа. Банк \~4 000 сотрудников, 14 регионов, 4 часовых пояса. Существующая IdM модернизируется: процесс запускает кадровое событие, права выдаются по ролям, учётные записи готовы к 09:00 первого рабочего дня.

**Начни с [`CHEATSHEET.md`](/case/cheatsheet/)** — там маршрут чтения, назначение каждого документа и подробный разбор всех диаграмм.

## Структура

| Папка              | Слой                     | Содержимое                                                                                |
| ------------------ | ------------------------ | ----------------------------------------------------------------------------------------- |
| `00_project/`      | Зачем                    | Устав, стейкхолдеры и RACI, глоссарий                                                     |
| `01_business/`     | Что меняется для бизнеса | AS-IS, TO-BE (BPMN + SVG-превью), gap-анализ, бизнес-требования                           |
| `02_requirements/` | Что делает система       | Use cases, ФТ, НФТ, ролевая модель, бэклог, матрица трассировки                           |
| `03_architecture/` | Как устроена             | C4 (контекст, контейнеры), модель данных, статусные модели, ADR                           |
| `04_integrations/` | С кем и как обменивается | Карта интеграций, sequence-диаграммы, маппинг, OpenAPI / AsyncAPI                         |
| `05_security/`     | Ограничения ИБ           | Требования ИБ, модель угроз и матрица доступа к API                                       |
| `06_rollout/`      | Как перейти              | Миграция данных, план внедрения, план релиза                                              |
| `07_testing/`      | Как доказать             | ПМИ, тест-кейсы                                                                           |
| `08_operations/`   | Как эксплуатировать      | Модель сопровождения, runbook, мониторинг, инцидент, разбор проблемы, запрос на изменение |

Нумерация папок — условный порядок «от зачем к как», а не стандарт.
