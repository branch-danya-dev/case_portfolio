Требования ИБ формулирует служба ИБ, но системный аналитик обязан встроить их в ФТ, НФТ, контракты и тесты. На практике этот документ собирается из внутренних стандартов банка, ГОСТ Р 57580.1 (меры по управлению учётными записями и правами логического доступа) и 152-ФЗ.
