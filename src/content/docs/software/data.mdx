<Brief>

Аналитику нужен **клиент БД**, чтобы исследовать незнакомую схему, писать SQL и проверять данные после теста, и **текстовые утилиты**, чтобы разбирать JSON и YAML из интеграций.
Универсальный клиент (DBeaver) закрывает большинство СУБД; «родной» клиент (SQL Developer, pgAdmin) удобен для планов выполнения.
Доступ — обычно только на чтение и к тестовым или обезличенным данным.

</Brief>

## Как выбрать

| Нужно | Инструмент |
|---|---|
| Подключиться к любой СУБД, писать запросы | DBeaver |
| Много сложного SQL каждый день | DataGrip |
| Проект на PostgreSQL / Oracle | pgAdmin / Oracle SQL Developer |
| ER-диаграмма существующей БД | DBeaver (по схеме) |
| Набросать логическую модель | dbdiagram.io, PlantUML, Mermaid |
| Разобрать большой JSON или YAML | jq, yq, VS Code |

## Типичные ошибки

| Ошибка | Чем плохо | Как правильно |
|---|---|---|
| Доступ на запись к продуктивной БД «для удобства» | Риск испортить данные, нарушение ИБ | Только чтение, тестовые стенды |
| Выгрузка ПДн в Excel на свой ноутбук | Утечка | Обезличенные данные, работа в контуре |
| Тяжёлый запрос на продуктиве в рабочее время | Нагрузка на систему | Реплика, ограничения, план выполнения |
| JSON вставляют в онлайн-форматтер | Утечка данных интеграций | jq, VS Code — локально |
