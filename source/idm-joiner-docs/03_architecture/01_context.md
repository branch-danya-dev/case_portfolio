# Контекст системы (C4, уровень 1)

Версия 1.0 · Статус: Согласован архитектурным комитетом · Автор: Архитектор решения (при участии СА)

Диаграмма: `diagrams/c4-context.puml`.

Контекстная диаграмма отвечает на вопрос **«где граница системы и с кем она взаимодействует»**. Внутреннее устройство IdM здесь не показывается. Это первая диаграмма, которую стоит нарисовать в любом проекте: по ней видно, сколько будет интеграций и чьих согласований они потребуют.

## Внешние системы

| Система | Роль для IdM | Направление | Владелец | Интеграция |
|---|---|---|---|---|
| HRMS (1С:ЗУП) | Источник истины о сотрудниках | HRMS → IdM; IdM → HRMS (сверка) | Команда HRMS | INT-01, INT-02 |
| Корпоративная шина (Kafka) | Транспорт событий | — | Команда интеграции | INT-01, INT-09 |
| Active Directory | Целевая система | IdM → AD | Администраторы AD | INT-03 |
| Exchange | Целевая система; отправка уведомлений | IdM → Exchange | Администраторы почты | INT-04, INT-08 |
| АБС | Целевая система | IdM → адаптер → АБС | Владелец АБС | INT-05 |
| ServiceDesk | Задачи ручного исполнения | IdM ↔ ServiceDesk | Служба поддержки | INT-06 |
| SMS-шлюз | Доставка одноразового пароля | IdM → SMS | Департамент ИТ | INT-07 |
| SIEM | Мониторинг событий ИБ | IdM → SIEM | Департамент ИБ | INT-09 |

## Пользователи

HR-специалист работает только в HRMS и с IdM напрямую не взаимодействует. Это важное проектное решение: процесс HR не меняется, кроме срока проведения приказа (GAP-09).

## Что не входит в контекст волны 1

Система PAM, СКУД (пропуска), ~40 прочих целевых систем. Их отсутствие на диаграмме — следствие скоупа в уставе.
