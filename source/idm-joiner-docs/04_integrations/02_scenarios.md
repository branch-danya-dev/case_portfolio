# Сценарии взаимодействия (sequence-диаграммы)

Версия 1.0 · Статус: Согласован · Автор: Системный аналитик

Sequence-диаграмма показывает **порядок сообщений между участниками во времени** для одного сценария. Она отвечает на вопросы разработчика: кто кого вызывает, в каком порядке, что возвращается, что происходит при ошибке. Хорошее правило: на каждый основной сценарий — одна диаграмма успешного пути и отдельные диаграммы для важных ошибок.

| ID | Сценарий | Файл | Требования | Тесты |
|---|---|---|---|---|
| SEQ-01 | Приём нового сотрудника: успешный сценарий от приказа до активации | `diagrams/seq-01-hire.puml` | FR-01 … FR-10, FR-15, FR-19 … FR-21 | TC-01, TC-06, TC-16 |
| SEQ-02 | Сбой АБС при создании пользователя: повторы, ручная задача, webhook | `diagrams/seq-02-abs-failure.puml` | FR-16, FR-17 | TC-12, TC-13 |
| SEQ-03 | Отмена приёма после создания учётных записей | `diagrams/seq-03-hire-cancelled.puml` | FR-18 | TC-09 |
| SEQ-04 | Заявка на дополнительный доступ с согласованием | `diagrams/seq-04-access-request.puml` | FR-12 … FR-14 | TC-14 |

## Обозначения PlantUML

| Элемент | Значение |
|---|---|
| `->` | Синхронный вызов |
| `-->` | Ответ |
| `->>` | Асинхронное сообщение |
| `->x` | Потерянное сообщение (не дошло до получателя) |
| `-[#red]->` | Цвет стрелки; здесь — для ошибок и таймаутов |
| `alt / else` | Альтернативные ветки (условие) |
| `loop` | Повторение |
| `== … ==` | Разделитель этапов во времени |
| `autonumber` | Нумерация шагов — на них удобно ссылаться в требованиях и тестах |
